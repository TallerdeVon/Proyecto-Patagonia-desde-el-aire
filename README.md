
### Por Taller de Von | Robótica • Drones • Soluciones inteligentes • bomberos • asistencia • todo por mi país


Este repositorio contiene toda la documentación técnica, modelos 3D y guías de ensamblaje para la construcción de drones de exploración diseñados en **Taller De Von**. El objetivo es crear una plataforma de vuelo robusta, capaz de capturar imágenes en entornos desafiantes como la Patagonia Argentina, detectar incendios, equiparse de manera poli funcional, detectar personas y caza furtiva. Tambien ser asistencia en zonas peligrosas para busqueda y rescate.

---

## 🛠️ Contenido del Repositorio
* **`/models`**: Archivos STL y fuentes para impresión 3D del chasis (frames).
* **`/electronics`**: Diagramas de conexión, esquemáticos de la PDB y controladores de vuelo.
* **`/config`**: Archivos de configuración para Betaflight/iNav o ArduPilot.
* **`/docs`**: Listado de componentes (BOM) y guías de ensamblaje paso a paso.

## ⚙️ Especificaciones Técnicas (v1.0)
* **Tipo:** Ala delta de exploración.
* **Controlador:** [SpeedyBee F405]
* **Motores:** [2207 1800KV]
* **Autonomía estimada:** [150-200 min]

## 🚀 Cómo empezar
1.  **Revisá la BOM:** Consultá el archivo `/docs/BOM.md` para conocer los materiales necesarios.
2.  **Impresión 3D:** Descargá los archivos de la carpeta `/models` (recomendado material PETG o Fibra de Carbono).
3.  **Ensamblaje:** Seguí la guía visual en nuestra wiki o carpeta de documentación.
